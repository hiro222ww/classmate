# X初期露出 — 返信候補（人手実行）

目的: 通常投稿の低インプレッション下で、公開会話への**自然な返信**を増やし接点を作る。  
**AIは下書きのみ。Xへの自動返信・自動DMはしない。**

## 前提
- マイグレーション: `supabase/migrations/20261122120000_marketing_reply_suggestions.sql`（本番適用は別途承認）
- 既存: 夕方ダイジェスト（`MARKETING_OPS_DIGEST_ENABLED`）・AI運営憲章・UTM計測
- Cron / Buffer / 即時投稿ゲートの既定値は変更しない

## 運営フロー（スマホ可）
1. Xで公開ポストを探す（音声通話・友だち作り・雑談・社会人交流）
2. `/admin/marketing` → 「初期露出：返信候補」に URL + 選定理由を登録
3. 本文が取れない場合は本文を貼って再生成
4. 返信案をコピー → **Xアプリで手動返信**
5. 管理画面で「投稿済み」または「見送り」
6. 可能なら views / プロフィール訪問を手入力。サイト流入は `utm_content=reply_…` で自動計測

## Discord
19:00 JST ダイジェストに「初期露出：返信候補」が付く（既存ゲートON時のみ。本PRはゲート値を変えない）。

取得できない指標は未計測のまま（推測しない）。
